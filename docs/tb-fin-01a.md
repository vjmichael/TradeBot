# TB-FIN-01A — paper financial goals and reporting candidate

Daily dollar goals, points and household cash-flow planning measure outcomes; they are never trading quotas or authorizations. Financial Goals is a dedicated authenticated dashboard tab scoped to one registered PAPER portfolio. No sum of overlapping research portfolios and no paper return is household income. Authorized principal is the existing virtual allocation, not an editable goal input. Saving a plan cannot alter risk, funding, Gate state or reserves. The new additive goal_versions table stores hash-linked version history and optimistic update identity. First settings apply today, later edits apply next local day. Default America/Phoenix; IANA zone selected at first save is locked until a separately designed calendar migration. No goal pause or new-entry policy is introduced here.

Monthly plan uses nonnegative integer cents, optional explicitly non-duplicated planned costs and estimated tax basis points strictly below 100%. Divide after-tax shortfall by (1-tax rate) and actual local month's length. Daily primary target can be none, USD or points; one point is 1% of known day-start active equity. Convert using only fixed historical authenticated evidence. Displayed values are Decimal strings rounded for display, never risk inputs. Day/month are local calendar windows, including DST/leap years. The immutable ledger's recorded_at is posting time, not an asserted exchange fill timestamp. P/L is change in booked realized profit including fees and corrections posted in the relevant interval; settled P/L is separate. Later corrections appear on their posting day. No double counting of reserve transfers. Show active cash, protected profit, earmarks, unrealized and active equity where a mark exists, actual service cost and withdrawal status as unavailable rather than invented.

The currently qualified native observation publisher provides only authenticated flat wallet evidence. A point baseline therefore requires the last financial event just before local midnight (within 30s) to be a matching authenticated flat wallet snapshot, with no intervening execution activity; derive the exact base and durable receipt from the original verified journal prefix. Never substitute an intraday balance for a missing baseline. Current report is posted-ledger progress, not proof of verified exchange or portfolio returns.
