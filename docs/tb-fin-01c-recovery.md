- reserve_recovery.py: strict recoverable authority IPC lane, rejects the old digest-only advance operation. Verifies the existing exact signed permit, validates canonical event hash against the real financial journal format, persists an immutable private recovery record before moving the monotonic witness, and returns the current protected record only to the authenticated desk peer. It inserts precisely the historical event under a savepoint; no reevaluation or silent rewind; already committed returns a nonmutating result. Old or ambiguous history, unavailable service and unreconciled state refuse. Records are not dropped merely on untrusted acknowledgement. Production caller must hold BEGIN IMMEDIATE and provide genuine replay/reconciliation. Historical permit verification is used only for the current already-advanced witness, not new advancement.
