Defaults 0% and missing required fields. The illustrative next-cycle calculation uses booked balances plus separately labeled hypothetical gain, excludes existing eligible surplus from new approval, clamps to room and policy limits, and respects known financial locks. It assumes future independent verification; it is not an expected return or actual release. Before/after graphic and amounts are informational. Explicit integer cents inputs converted on server; no JavaScript money authority.

Apply/Update appends separate hash-linked draft versions with optimistic concurrency to reserve_drafts, never the financial journal. Drafts persist on restart and remain separate from the engine's existing signed saved/active policy. Discard is local only; saving never changes the active policy, capital, reserves, risk, or paper state. Review only the current saved version; expired/disputed/stale versions refused. The exact policy and informational broker payload are available in review; no signing or production approval route. No credentials, password or broker key enter the dashboard. Existing operator broker requires independent revalidation, actual engine reserve_save, explicit strong human review and fresh authenticated approval. Current recorded authority is read-only and is not presented as independently verified green ON.
