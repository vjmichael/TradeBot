Repeated observations deduplicated, discrepant same-time values withheld, collector success/failure persisted. All requests are public and use no Grok/LLM or vault credentials.

Native DuckDB 1.4.4 candidate writes immutable compressed Parquet windows with exact round-trip, SHA-256, manifest, private paths. Retains staging values for now; DuckDB analytical read path over partitioned long history, archival compaction, quota/restore and native qualification are not yet complete. Query uses SQLite staging and not a pretend Parquet-backed production lake.
- Deterministic hourly and 168 weekday/hour profiles, UTC and supported IANA zones, DST counts, coverage by bin, mean high-low % of open, mean absolute open-to-close log return, mean base volume. Missing bins null. No claim of realized sub-hour volatility, spread, depth or slippage. Authenticated dashboard heatmap with 30/90/365/1825-day windows; older full coverage profiles await acquisition. No unmeasured signal/return claims.
- Numerical-only graphical instance plan requires neither a Grok model nor a budget, provider=none, with server-side validation; legacy records retained. All instances remain PAUSED/paper only. No research/execution/start endpoint.
