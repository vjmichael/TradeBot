# TB-04A — AI-independent market memory intake and session-analysis candidate

Authority: v0.7 plus v0.8 addendum. TB-03 closed at 138bba1e (locked browser and foundation). This is a bounded intermediate implementation, not a claim of full historical readiness or live trading.

## Implemented

- Separate private SQLite WAL market catalog, source identity/hash, explicit acquisition and publication times, durable import cursor, exact normalized OHLCV decimals, source references and revision tracking. Developer/operator-staged headerless Kraken OHLCVT CSVs bound to pair/interval filename and expected SHA-256, privately copied before ingestion. Physical bounded lines/batches, malformed and out-of-order rejection, incomplete/invalid source invisibility, resume at committed offset. A checksum provided by the operator proves byte identity, not independently verified archive provenance/licensing. No archive download bundled. Fixture data never enters non-fixture queries. Missing intervals are counted and not synthesized; Kraken archives omit intervals without trades, so missing is not automatically an outage.
- Public REST poller for the three supported spot pairs, hourly closed observations, using already qualified adapter. Explicit developer-only polling loop; no autonomous service started now. Repeated observations deduplicated, discrepant same-time values withheld, collector success/failure persisted. All requests are public and use no Grok/LLM or vault credentials.
- Bounded point-in-time query from staging catalog, source publication visibility cutoffs, conflict/missing counts. Native DuckDB 1.4.4 candidate writes immutable compressed Parquet windows with exact round-trip, SHA-256, manifest, private paths. Retains staging values for now; DuckDB analytical read path over partitioned long history, archival compaction, quota/restore and native qualification are not yet complete. Query uses SQLite staging and not a pretend Parquet-backed production lake.
- Deterministic hourly and 168 weekday/hour profiles, UTC and supported IANA zones, DST counts, coverage by bin, mean high-low % of open, mean absolute open-to-close log return, mean base volume. Missing bins null. No claim of realized sub-hour volatility, spread, depth or slippage. Authenticated dashboard heatmap with 30/90/365/1825-day windows; older full coverage profiles await acquisition. No unmeasured signal/return claims.
- Numerical-only graphical instance plan requires neither a Grok model nor a budget, provider=none, with server-side validation; legacy records retained. All instances remain PAUSED/paper only. No research/execution/start endpoint.
